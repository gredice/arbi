# Positioning-line source ownership

The four line and slip-ring visualizations now belong to the [winch source directory](../winch/README.md#winch-owned-line-and-power-visualizations), following [ADR-0010](../../../docs/decisions/0010-corner-support-and-winch-line-ownership.md). Their model IDs, revisions, geometry and release output names are unchanged. This retained page keeps existing documentation links usable.

The [shared positioning-line specification](../../../docs/assemblies/positioning-lines/README.md) defines construction, inspection and replacement requirements; it is not a separate assembly or BOM owner.
