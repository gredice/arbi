# Pod runtime and health provenance

[The pod application](../../apps/arbi-pod-firmware/README.md) runs a foreground service supervised by systemd. [ADR-0026](../decisions/0026-inhibited-pod-service.md) selects the source/runtime boundary. The ordinary executable starts without secrets on loopback health, with no camera/gimbal device access and no enrolled TLS listener until a protected local manifest is supplied. Invalid startup/configuration exits 78 with a bounded redacted error. SIGTERM inhibits the adapter first, closes sockets/timers and camera lifecycle, then closes local stores. The unit bounds restart attempts, memory, tasks, descriptors and shutdown; the selected Pi image has not verified enforcement.

Authenticated diagnostics reuse the [edge local transport](edge-runtime.md). TLS 1.3 verifies the CA and exact enrolled edge certificate plus ALPN. The pod admits one current peer, uses fresh boot/session identities and requires exact nine-field discovery/version/site/realm/configuration compatibility. A fixed 16,384-byte decoder rejects size before payload copy; input is limited to 32 frames/second, handshake 1,500 ms, incomplete-frame idle 250 ms / total 1,000 ms, checked on a 250 ms diagnostic timer. Output is limited to 32,768 queued bytes. Idle established peers receive snapshots without gaining actuator authority. Discovery and resync do not execute gimbal/capture work.

The shared command parser and admission ledger reject incompatible, unauthorized, expired, wrong-epoch and unsupported input. Only the edge's explicitly authorized synthetic `state.resync` actor is supported. Duplicate commands return no second dispatch or record. Disconnect discards the receiver ledger and creates a fresh session; old target/deadline epochs are rejected. Process restart creates a fresh boot and never restores movement, grants or old capture intent. Camera initialization accepts only a trusted simulated adapter; real adapters remain unavailable, and no readiness statement enables physical output.

Health reads `/sys/class/thermal/thermal_zone0/temp`, bounded `vcgencmd get_throttled`, `statfs` and OS network-interface state where available. Each value declares measurement/OS-flag/estimate kind, source, OS or simulated origin, quality and local sample time. Missing, malformed or timed-out probes remain null/unavailable. Current and historical undervoltage/throttling flags remain distinct. Network configuration is an estimate, not Internet or carrier availability. Voltage has no sensor and reset cause has no adapter; OS boot identity alone does not infer brownout. Process RSS/CPU is an OS report with a local sample time; build identity records actual Git SHA/dirty state and unknown archive fallback. No addresses, credential files or media enter health output.

RAM logs retain 128 fixed-field records and count eviction/suppression. SQLite informational diagnostics retain 128 records of at most 2,048 bytes under a 256-page cap. They persist across restart and link accepted/rejected diagnostics to boot, connection, sequence and correlation IDs. These records are not `AuditEvent` authorization or physical effect evidence. Actual edge grants use the existing shared vocabulary. The pod's shared audit spool allows 256 events / 1 MiB / 512 pages and grants no new authority; this foundation emits no fabricated pod authorization event. Its shared traffic spool allows 512 records / 1 MiB / 512 pages and meters actual TLS plaintext send/receive attempts as separate application/LAN observations. WAN, carrier and health-HTTP network bytes remain unavailable; no two observation boundaries are summed into a total.

Tests exercise actual TLS sockets, the independent existing edge adapter, real SQLite persistence, command replay/revision/size/JSON/certificate refusal, deterministic camera/health adapters and an actual killed/restarted child. The executable is tested under the 64 MiB old-space limit. [Evidence](../evidence/pod-runtime.md) separates these source/host observations from the absent named Pi 3A+ startup, camera, physical controls and resource record.
