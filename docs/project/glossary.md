# Glossary

| Term | Meaning in ARBI |
| --- | --- |
| ARBI | Automatic Raised Bed Imaging system. |
| Anchor | Fixed three-dimensional coordinate at a corner positioning-line pulley. |
| Assembly | A physical, replaceable or inspectable unit that owns its component quantities and interfaces. |
| Build manifest | A versioned selection of assembly revisions, quantities, variants, and procurement choices for one build. |
| Cable spider | The central pod structure where the four positioning lines attach. |
| Corner station | Post, foundation/guying, pulley head, mounting interfaces, and local routing at one corner. The winch is a separate mounted assembly. |
| Dock | The high corner-mounted nest, latch, shelter, and sensor used for automatic parking. |
| Edge service | Local service that queues jobs, coordinates motion and pod actions, enforces operating policy, and tolerates Internet outages. Exact hardware is undecided. |
| Fiducial | Permanent visual marker used to estimate image position, rotation, perspective, and scale. |
| HOME | Calibrated location and transition used to reach the dock. HOME is not by itself proof that the mechanical latch engaged. |
| Hybrid line | Dyneema positioning line with mechanically slack electrical conductors helically wrapped around it. Dyneema carries tensile load. |
| Maintenance mode | Manually initiated, access-controlled state that may lower the pod after the area is cleared. It is never an automatic parking state. |
| Offer | Supplier-specific commercial terms for a compatible part, including SKU, pack size, price, currency, MOQ, destination, shipping assumptions, and verification date. |
| Parked | State entered only after the dock mechanically retains the pod and docking confirmation is accepted. |
| Part | A uniquely identified engineering item independent of its supplier offer. |
| Positioning line | One of four motor-controlled lines defining the pod position. |
| PRE-DOCK | Approach position near the dock where speed is reduced before mechanical capture. |
| Proof load | Controlled applied load used to inspect an assembly against defined acceptance limits. It is not a substitute for engineering analysis. |
| Single-layer drum | Winch drum sized to avoid multiple line layers and their changing effective radius. |
| Skycam motion | Coarse three-dimensional pod positioning by coordinated changes to four line lengths. |
| Starting point | Initial commissioning value that must be tuned from measured evidence. |
| V1 | First intended reproducible outdoor release, not merely the first moving prototype. |
