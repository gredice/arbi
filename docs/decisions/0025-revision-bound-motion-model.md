# ADR-0025: Revision-bound isolated motion model

Status: accepted when the issue PR merges. Work record: [#52](https://github.com/gredice/arbi/issues/52).

The [shared configuration](../software/configuration.md) remains the site, hardware, geometry, calibration and limit authority. The simulator derives an immutable test model from a validated test/simulation configuration plus explicit trusted per-axis mechanics. A digest binds the complete configuration and mechanics. These mechanics are not new network command fields or a parallel configuration protocol. The bounded C core receives a trusted, copied profile; USB commands and ordinary startup cannot provision it or gain motion capability.

Select constant-radius, single-layer drums, explicit full steps and microsteps per turn, direction polarity, cable-length home reference, home count, cable travel and count limits. Pose conversion uses millimetres in the versioned site frame. The first numerical model supports ordered rectangular coplanar a/b/c/d anchors and the branch below the anchor plane. Unsupported layouts are rejected. Quantized count estimates use four sphere residuals with a declared four-microstep cable tolerance. Sag, elasticity, helix, changing effective radius, missed steps and tension are outside this model.

Each finite segment is admitted before publication. The C core checks identity, units/frame, finite arithmetic, workspace, absolute travel, at most 512 steps per axis, requested speed/acceleration, per-axis rate/acceleration ceilings, pulse duration and every quantized estimated pose in the actual pulse words. Speed includes an endpoint-average estimate check; acceleration is the declared discrete step envelope. These checks are not continuous physical Cartesian dynamics or mechanical protection. The shared simulator and firmware agree on the same geometric conversions; installed position remains unavailable.

One pending/active segment prevents competing state updates. The receiver rechecks all profile identities before beginning and on every commanded-progress observation/completion. An identity mismatch, contradictory count or invalid replacement latches inhibition and discards pending intent. Returning to the former revision never restores readiness automatically; a trusted deliberate reference/profile restore is required. Completed counts and pose are commanded/estimated data, never encoder or tension measurements. This numerical state machine has no GPIO calls and cannot implement the independently reviewed physical stopping policy.

The [guide](../software/motion-geometry.md) and [evidence](../evidence/motion-geometry.md) define the numerical scope. Physical motion remains gated by the [pulse-engine decision](0024-isolated-synchronized-pulse-engine.md) and local safety acceptance.
