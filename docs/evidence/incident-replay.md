# Incident replay software evidence

Scope: [#54](https://github.com/gredice/arbi/issues/54), [ADR-0017](../decisions/0017-read-only-incident-replay.md). Source baseline is `3b9f17527cb8b94020e7daae156f28ad53e60b0b`; the named affine model in the comparison uses that committed source revision. The incident contains public synthetic protocol/accounting/audit fixtures, with original raw clocks and declared synthetic software references. No real coordinates, credential, media bytes or bench recording is included.

Deterministic tests seek and restart the same fault/command prefix, pause without advancing, scale explicit elapsed time, preserve missing/out-of-order/duplicate ranges and flag identity conflicts. Integrity, configuration mismatch, resource limits, unit mismatch and accessor/cycle rejection are tested. Redaction tests replay the surviving export while checking raw command/sensor data and identities are absent. The real CLI runs control-bearing recorded messages while a mock live-control HTTP listener receives zero requests.

Protected-reader fixtures use real ephemeral Gredice credentials and current policy. They test raw read versus independent export authority, viewer denial before storage access, corrupt/foreign scope, expiry/bench retention, missing required audit acknowledgement, revocation during storage reading, unsupported methods and preview suppression of configured providers. These source callbacks test boundary behavior, not native database durability or physical identity. Existing canonical/native audit evidence remains separate.

The committed model-comparison report compares an explicit synthetic measured-voltage fixture to the actual affine plant prediction, with a declared synthetic offset. Bias/RMSE are approximately 0.6 V over one declared voltage sample; the report carries original value/time uncertainty, parameter bounds, exact data/model identifiers and exclusions for commanded position and unavailable tension. It reports physical evidence unavailable. This is a report-format and arithmetic check, not a physical model acceptance result.

Run conditions: isolated Linux x64 workspace with Node 24.19.0 and pnpm 11.5.2; synthetic source records, ephemeral identity keys and an owned loopback listener. Local validation passed: 129 simulation checks, 87 dashboard source checks (15 native-only cases skipped), the production build/lint, ordinary and preview HTTP probes, and 279 documentation link checks. The issue PR records review/CI. Missing evidence: a named private physical bench recording, independent recording provenance/custody review, physical operating-range coverage and qualified model/calibration review. None is inferred from CI, self-hashes or replay.
