# Update dashboard software evidence

Scope: [#75](https://github.com/gredice/arbi/issues/75), [ADR-0021](../decisions/0021-isolated-update-dashboard.md). Local reviewer: Codex. Setup: Linux x64, Node 24.19.0, pnpm 11.5.2, Chromium 145, PostgreSQL 18.4 in a fresh socket-only database, built Next.js application, a separately running actual edge UpdateServer, real authenticated loopback HTTP Range source and private persistent SQLite synthetic targets. Credentials and signing keys are ephemeral and private.

The browser checks an engineer can read inventory but cannot request an update, and explicitly lists drivers as unsupported managed targets. A separate site-bound updater profile rejects a signature-invalid release, requests one Pico target, observes 4,096 interrupted response-body bytes, reloads and attaches the same URL operation with one request. The next range retains 69,632 bytes. Active motion blocks staging activation while installed firmware remains the baseline. A failed trial rolls back to observed healthy baseline and halts the group. Offline clears protected progress; reconnect/read restores the same operation without resubmission. A new explicit consented request and recorded 250,000-byte override complete Pico, pod and finally edge, with health confirmation required for success.

Native PostgreSQL checks independently verify updater login, one authorized site, separate update/engineering capabilities, no motion permission, membership revocation and session revocation across independent instances. Actual HTTP proxy tests preserve the user bearer, strip cookies, use constructor-bound private transport, reject external/production configuration and cap oversized replies. Build identity tests preserve unknown provenance rather than inventing a revision.

These results establish isolated browser/service/data behavior. The public publisher may remain unavailable and does not clear production key custody or deployed web acceptance. No physical board, passive restraint, actuator, carrier modem, power interruption, Linux slot recovery or qualified field procedure is tested; physical installation remains disabled. CI and reviewed software revision are recorded on the issue PR.

Local validation: all 19 browser scenarios pass, including the two update flows; dashboard source suite passes 91 checks with 15 native-only skips; separate native PostgreSQL suite passes 68 checks; 28 existing edge update/security/transfer checks and the expanded 12-scenario operation suite pass. Dashboard/edge build, dashboard lint, ordinary/preview built HTTP guards, 291 documentation checks and whitespace validation pass. The expanded operation suite also demonstrates that a corrupt 256-byte actual response body is fully charged, fails digest verification, preserves the installed/confirmed baseline and creates no device-outcome success.
